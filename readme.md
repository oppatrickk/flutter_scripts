# Scripts

These are a compilation of scripts being used on flow_app

## Setting Up

Add the script folder to your PATH.

## Current Scripts

- [analyze.sh](#analyze)
- [check_dependency.sh](#check_dependency)
- [rebuild.sh](#rebuild)
- [restart_build.sh](#restart_build)
- [start_build.sh](#start_build)
- [translation.sh](#translation)


### analyze.sh
Use this script to analyze the project

### rebuild.sh
Use this script after you freshly clone the project. Running this script is required to run the project. This script generates the necessary files.

### restart_build.sh
Use this script to restart build_runner

### start_build.sh
Use this script to generate build_runner

### check_dependency.sh
This script checks our dependencies for unused items.

### translation.sh
Use this script to manually generate the localizations
